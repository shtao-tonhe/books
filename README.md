# 荐书

一个古雅且沉浸的个人荐书站，基于纯静态 HTML/CSS/JS 构建，部署于 GitHub Pages。

## 本地预览
直接用本地服务器打开即可（fetch 加载 JSON 需要 http 环境）：
```bash
# Python
python -m http.server 8000
# 或 Node
npx serve .
```

访问 http://localhost:8000

## 添加新书
1. 把封面放到 `assets/covers/`
2. （可选）把源文件放到 `files/`
3. （可选）把 AI 图谱放到 `assets/img/`
4. 在 `data/books.json` 按 schema 新增一条记录
5. 提交推送到 GitHub，Pages 自动部署

## 卡片交互（悬停描边 + 详情弹层）
- hover 卡片：封面放大、卡片上浮，并沿卡片**外轮廓的真实路径**从 0 → 100% 匀速描边
- 持续悬停 **5 秒**（描边刚好画满）后自动打开详情弹层；中途移开则描边淡出复位
- 点击卡片 / 聚焦后按 Enter 可跳过等待直接打开；Esc、点击遮罩或关闭按钮收起
- 弹层内容只有简介文本（`intro`，缺失时用 `description`），保留关闭与查看详情两个按钮
- 描边时长只有一处配置：`css/tokens.css` 的 `--dur-trace`（JS 会读取它）
- 描边用 SVG `pathLength="1"` 归一化路径长度，配 `stroke-dashoffset: 1 → 0`，
  因此 0→100% 与真实周长严格线性对应；卡片尺寸变化由 ResizeObserver 重算路径
- 支持 `prefers-reduced-motion`（关闭缩放/位移动效，保留描边）；触屏设备用点击打开

## 顶部栏（滚动形态切换）
- 页面未滚动时完全透明：左侧无站点信息，右侧只有放大镜 + 明暗切换
- 滚动越过顶部大图后，整条栏淡入一层毛玻璃底 + 下边线，同时放大镜滑到**正中并展开成搜索框**
- 搜索实时过滤书架（书名 / 英文名 / 作者 / 标签 / 出版社），与标签筛选叠加；无结果时显示空状态
- 顶部直接点放大镜也能展开；Esc 先清空关键词、再收起；输入框失焦且无关键词时自动收起
- 详情页只有「返回书架 + 明暗切换」，复用同一套滚动逻辑
- 触发阈值固定为滚动 **100px**（`js/header.js` 的 `CONDENSE_AT`），与顶部大图多高无关；
  回滚方向留了 24px 迟滞，避免在阈值附近来回抖
- 顶部大图高度用 `--banner-h`（`css/base.css`，默认 `clamp(360px, 48vh, 680px)`）控制，
  正文起始位置共用同一个变量，改一处两边不会错位
- 吸顶后是一层**高斯磨砂**（`backdrop-filter: blur(28px) saturate(1.2)` + 84% 页面底色，
  深色 88%），下方滚过的正文会被糊成色块，不会和顶栏控件叠字
- ⚠️ 顶栏上**不要**再挂 `fade-in` 这类 `animation-fill-mode: forwards` 的透明度动画：
  Chrome 会把该元素当成合成组，导致 `::before` 的 `backdrop-filter` 采不到页面内容，
  玻璃会静默失效（只剩一层半透明色）。顶栏自己的入场动画 `header-in` 故意不带 fill。

## 排列方式（横向 / 竖向）
- 两种排列：`list` = 一行两个、封面在左信息在右（默认）；`poster` = 原来的竖向封面卡片
- 筛选栏右侧的小开关切换，选择记在 localStorage 的 `jianzhu-view`
- 切换靠 `[data-shelf][data-view="list"]` 一组作用域 CSS 完成：只改网格与卡片内部方向，
  卡片 DOM、悬浮描边、详情弹层、星尘占位全部复用，不用两套结构
- 宽屏 2 列 → ≤900px 自动 1 列（用 `minmax(0, 1fr)`，否则 1fr 的 min-content 会把卡片撑破视口）
- 横排时封面**铺满整个左栏**（无内边距，圆角由卡片本体裁切），左栏高度按封面比例由宽度推出，
  信息栏更高时封面会拉伸并由 `object-fit: cover` 裁一点边
- 横排不做 hover 放大（竖排仍有）；两种排列下所有卡片高度一致：无封面卡片有隐形占位框，
  网格行高用 `grid-auto-rows: 1fr`，卡片内容块 `flex: 1 1 auto` 填满单元格

## 待读（无封面）星尘占位
- 没有 `cover` 的书，卡片封面区会渲染星尘粒子层（`js/spoiler-particles.js`），并直接使用自身的 `coverPalette` 配色；
  封面上的「待阅读 / TO READ」文字已移除，只保留星尘；

  无封面卡片不再套 `is-inactive` 灰化，所以默认就是完整亮度/配色（即原来 hover 时才有的观感）
- 粒子层**常驻**：不做点击消散，弹窗关闭后依然在；离屏或弹窗收起时自动暂停 rAF，不空转
- 详情弹层里只有简介正文 + 「关闭 / 查看详情」两个按钮，封面、标题、评分、标签都不再重复展示
- 亮度/密度在 `spoiler-particles.js`：`baseAlpha` 控制亮度，`initSpoiler(canvas, { min })` 控制最少粒子数

## 设计特点
- 实体书籍卡片 + 悬浮信息卡
- 封面主色提取氛围光
- 明暗主题切换
- 标签筛选、置顶排序
- 详情页：基础介绍、AI汇总（文字/核心/图谱）、金句、延伸阅读、相关推荐、源文件
